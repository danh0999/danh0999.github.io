# Đặng Đức Anh — Technical BA Portfolio & ATS CV

Minimalist, recruiter-ready Portfolio website and 1-page ATS-friendly English CV built from verified project artifacts (`Hokori-Learning` & `blood-donation`).

## Project Structure
- `index.html`, `styles.css`, `script.js` — Minimalist Portfolio website with interactive Hokori portal tabs and native `<dialog>` diagram/screenshot lightbox.
- `cv.html` — 1-page ATS-friendly English CV (click **Print / Save as PDF** in Chrome/Edge to export A4 PDF cleanly).
- `cv-ats.md` — Plain-text Markdown version of the ATS CV for quick pasting into Word / Google Docs.
- `assets/` — Real project artifacts extracted from your local Capstone & SWP documentation:
  - `hokori-main-flow.png` — Learner Main Workflow Diagram
  - `hokori-ucd.png` — 5-Actor System Use Case Diagram
  - `hokori-erd.png` — Relational Database ERD
  - `blood-checkup.png` — Pre-Donation 9-Section Health Screening Form UI
  - `blood-homepage.png` — Donor Portal Homepage & Date-Range Search UI

## Quick Launch Checklist Before Applying
1. **Fill in Contact Placeholders:** Search for `[FILL IN:` in `index.html`, `cv.html`, and `cv-ats.md` and replace with your Email, Phone, and LinkedIn URL.
2. **Export 1-Page PDF CV:** Open `cv.html` in Chrome/Edge → click **Print / Save as PDF** → set **Margins: None** (handled by `@page`) and disable **Headers and footers**.
3. **Check GitHub Repo Visibility:** Both `danh0999/Hokori-Learning` and `danh0999/blood-donation` are currently **Private**. Before switching them to **Public**, verify no `.env` secrets or Firebase keys remain in Git history, and add a clean English `README.md` to each repo.
4. **Optional Upgrade (High Impact):** Record a 60–90s walkthrough video of Hokori (Learner AI Kaiwa + Admin AI Packages) or capture 2 live UI screenshots and replace the `.placeholder-banner` in `index.html`.
5. **Deploy Free in 2 Minutes:** Push this folder to a new GitHub repo (e.g., `danh0999.github.io`) and enable GitHub Pages, or drag-and-drop / import directly on Vercel.
