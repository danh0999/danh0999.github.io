# Đặng Đức Anh — Technical Business Analyst Portfolio & ATS CV

Minimalist Portfolio website and 1-page ATS-friendly English CV (hosted on Vercel & GitHub Pages).

- **Live Portfolio:** https://dang-duc-anh-portfolio.vercel.app (mirror: https://danh0999.github.io)
- **1-Page ATS CV:** https://dang-duc-anh-portfolio.vercel.app/cv.html
- **Sample BA Spec & Test Scenarios:** https://dang-duc-anh-portfolio.vercel.app/hokori-ba-spec.html

## Structure
- `index.html`, `styles.css`, `script.js` — Portfolio website with Hokori, Blood Donation, and RatioPack Batch Pro case studies.
- `cv.html` — 1-page ATS-friendly English CV (print to A4 PDF with **Margins: None** and **Headers/Footers: Off**).
- `cv-ats.md` — Plain-text Markdown version of the CV.
- `hokori-ba-spec.html` — 2-page Feature Specification & Test Scenarios sample from the Hokori Capstone project.
- `assets/` — Project diagrams, UI screenshots, portrait, and PTE Academic score report (`pte-score-report.pdf`).
